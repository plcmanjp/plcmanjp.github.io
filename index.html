DESKTOP TOOLS

Windows에서 쓰는 공개 배포 도구입니다.

Windows · DXF

Excel CAD Label Maker

Excel의 글자를 전기함 덕트 라벨용 DXF 도면으로 만듭니다. .xlsx와 .xls 불러오기, 표 편집과 도면 미리보기를 지원하며 원본 Excel은 보존합니다.

DWG는 직접 생성하지 않습니다.

Windows 다운로드 ↗소개와 사용 안내
Windows · PLC

Q-FX Converter

FX5와 Q 계열 프로젝트의 래더 텍스트와 코멘트를 검토하고, 반대 계열의 GX 가져오기용 CSV 후보를 만듭니다.

PLC 접속과 다운로드 기능은 없습니다. 생성 결과는 GX와 실제 설비에서 별도로 검증해야 합니다.

Windows 다운로드 ↗지원 범위와 사용 안내

03 — OPEN SOURCE

코드부터 살펴보고 싶다면.

지원 범위와 검증 조건을 확인한 뒤 활용하세요.

Python · 오프라인 연구 도구

GX RE Toolkit

명시된 GXW와 GX3 프로젝트 형식을 오프라인으로 분석하는 독립 연구 도구입니다.

지원 CPU와 형식별 제한이 있습니다. 분석 성공이 GX 재빌드나 PLC 적용 안전성을 보장하지 않습니다.

소스와 지원 범위 ↗한국어 안내
Kotlin/JVM · 통신 라이브러리

MELSEC MC Kotlin

MC Protocol 3E/4E, TCP/UDP와 Binary/ASCII 통신을 지원합니다. Android SDK 없이 읽기와 명시적 쓰기 기능을 사용할 수 있습니다.

소스 빌드 방식이며 Maven에는 미배포 상태입니다. 공개판 검증은 실PLC 비연결 범위이므로 실제 설비 적용 전 별도 검증이 필요합니다.
