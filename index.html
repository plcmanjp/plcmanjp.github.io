02: DESKTOP TOOLS

도면 준비와 프로젝트 검토.

Windows에서 바로 내려받아 쓰는 공개 배포 유틸리티입니다.

WINDOWS / DXF

Excel CAD Label Maker

Excel의 글자를 전기함 덕트 라벨용 DXF 도면으로 만듭니다. .xlsx와 .xls 행 기준 불러오기, Excel 없는 직접 표 편집, 도면 미리보기와 설정 프리셋 재사용을 지원하며 원본 Excel은 변경하지 않습니다.

  • 행 기준 A/B/C열 변환
  • 표 편집과 프리셋
  • 실시간 DXF 미리보기

출력 형식은 DXF이며 DWG는 직접 생성하지 않습니다. 글꼴과 최종 치수는 사용하는 CAD에서 확인하세요.

Windows 다운로드 ↗ 소개와 사용 안내 ↗
WINDOWS / PLC

Q-FX Converter

FX5와 Q 계열 프로젝트의 래더 텍스트와 코멘트를 검토하고, 반대 계열의 GX 가져오기용 CSV 후보를 만듭니다. 자체 작성 앱 소스는 MIT 라이선스로 공개하며 포함된 외부 라이브러리에는 별도 조건이 적용됩니다.

  • 사용자 주소 규칙 매핑
  • GX 가져오기 CSV 후보
  • MIT 앱 소스 공개

PLC 접속과 다운로드 기능은 없습니다. 생성 결과는 GX와 실제 설비에서 별도로 검증해야 합니다.

05: OPEN SOURCE

코드부터 살펴보고 싶다면.

지원 범위와 검증 조건을 확인한 뒤 프로젝트에 활용하세요.

KOTLIN / JVM / COMMUNICATION LIBRARY

MELSEC MC Kotlin

Mitsubishi MELSEC PLC의 MC Protocol 3E/4E 통신을 위한 독립 Kotlin/JVM 라이브러리입니다. TCP/UDP 전송과 Binary/ASCII 인코딩, 일괄 읽기와 명시적 쓰기, CLI 예제를 Android SDK 없이 빌드해 사용할 수 있습니다.

소스 빌드 방식이며 Maven에는 미배포 상태입니다. 공개판 검증은 실PLC 비연결 범위이므로 실제 설비 적용 전 별도 검증이 필요합니다.
