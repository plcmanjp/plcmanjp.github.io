PLC 업무수첩 - MELSEC IO 체크

Mitsubishi MELSEC Q와 iQ-R PLC에 Ethernet으로 직접 연결해 현장 I/O를 점검하고 모니터링하는 Android 앱입니다.

  • 순차 IO 체크
  • 실시간 디바이스 모니터링
  • 배치 조회와 그룹 보기
  • GX Works2와 CSV 가져오기
  • 현장 계산 도구
설치 조건Android 8.0 이상. 사용자가 지정한 PLC와 통신할 수 있는 네트워크가 필요합니다.
개인정보 처리연결 설정과 프로젝트는 기기에 저장됩니다. 지정한 PLC와 직접 통신하며 Google AdMob 광고가 포함됩니다. 방침 보기

JP's Codeless Macro Tool

마우스와 키보드 동작을 녹화하거나 스텝으로 조립해 코딩 없이 Windows 반복 작업을 자동화합니다.

  • 동작 녹화와 스텝 편집
  • 조건, 반복, 변수
  • 이미지 검색과 OCR
  • 즐겨찾기와 포인터
  • 백그라운드 입력
설치 조건Windows 10 버전 1809(빌드 17763) 이상, x64 환경이 필요합니다.
개인정보 처리계정, 텔레메트리와 광고 SDK가 없습니다. 매크로, 캡처와 OCR 결과는 사용자 PC에서만 저장 및 처리됩니다. 방침 보기

FeedGrove - RSS 피드 리더

RSS, Atom과 일반 웹페이지를 한곳에 모아 읽고 규칙 기반 다이제스트로 정리하는 로컬 우선 피드 리더입니다.

  • RSS와 Atom
  • HTML 파서 스튜디오
  • 검색, 읽음, 즐겨찾기
  • 규칙 기반 다이제스트
  • 선택형 Discord 전송
설치 조건Android 8.0 이상. Google 그룹에 먼저 가입하고 같은 Google 계정으로 테스트 등록과 설치를 진행해야 합니다.
개인정보 처리개발자 수집 서버 없이 앱 데이터를 기기에 저장합니다. 사용자가 활성화한 Discord 전송에서는 콘텐츠 정보가 제3자인 Discord로 전달될 수 있습니다. 방침 보기
