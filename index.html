OPEN SOURCE

개발자와 연구자를 위한 공개 소스

Python오프라인 연구 도구

GX RE Toolkit

명시된 GXW와 GX3 프로젝트 형식을 오프라인으로 분석하는 독립 연구 도구입니다.

지원 CPU와 형식별 제한이 있습니다. 분석 성공이 GX 재빌드나 PLC 적용 안전성을 보장하지 않습니다.

소스와 지원 범위한국어 안내
Kotlin/JVM통신 라이브러리

MELSEC MC Kotlin

MC Protocol 3E/4E, TCP/UDP와 Binary/ASCII 통신을 지원합니다. Android SDK 없이 읽기와 명시적 쓰기 기능을 사용할 수 있습니다.

소스 빌드 방식이며 Maven에는 미배포 상태입니다. 공개판 검증은 실PLC 비연결 범위이므로 실제 설비 적용 전 별도 검증이 필요합니다.

HOW IT IS BUILT

현장 기준으로 단순하게 만듭니다

보여주기 위한 기능보다 실제 업무에서 반복되는 문제를 줄이는 데 우선순위를 둡니다.

01

현장 중심 설계

작업 흐름을 끊지 않고 필요한 기능에 빠르게 접근할 수 있도록 구성합니다.

02

지원 범위 공개

지원 운영체제, 연결 조건과 제품의 제한 사항을 제품별 페이지에 명확히 안내합니다.

03

데이터 처리 투명성

저장 위치와 외부 전송 여부를 제품별 안내와 개인정보처리방침에서 확인할 수 있습니다.
