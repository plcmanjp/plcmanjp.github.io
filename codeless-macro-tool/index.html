01

반복 입력

같은 양식에 다른 번호와 값을 차례대로 넣는 작업을 변수와 반복으로 처리합니다.

02

화면 확인

버튼이나 알림이 나타날 때까지 기다리고, 이미지와 텍스트를 인식해 다음 동작을 결정합니다.

03

정해진 절차

여러 프로그램을 오가며 반복하는 클릭과 키 입력 순서를 재사용 가능한 매크로로 저장합니다.

CAPABILITIES

단순한 매크로보다
한 단계 더 깊게

녹화한 동작 위에 판단과 데이터를 더해, 실제 업무에 맞는 자동화 흐름을 구성합니다.

BUILD

녹화하고, 스텝으로 다듬기

실제 마우스와 키보드 동작을 녹화해 스텝으로 바꾸고, 필요한 곳만 직접 추가하거나 순서를 조정할 수 있습니다.

  • 클릭, 더블클릭, 드래그와 스크롤
  • 단일 키, 조합키와 긴 텍스트 입력
  • 보기 모드와 편집 모드 분리

SAFE

실행 전 검사와 정상본 복구

반복, 조건, 포인터 구조와 누락된 이미지, 대상 창 설정을 재생 전에 확인합니다. 기존 프로젝트를 덮어쓸 때는 직전 정상본을 자동으로 한 세대 보관합니다.

  • 문제가 있으면 실제 입력을 시작하기 전에 중단
  • 실행 스텝, 반복 횟수와 전체 시간에 안전 한도 적용
  • 민감한 입력값을 남기지 않는 실행 기록

    동작 가져오기
