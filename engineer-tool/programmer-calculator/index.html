프로그래머 계산기

값 하나를 16진수, 10진수, 8진수, 2진수로 동시에 보여 주는 계산기입니다. 어느 진법에 입력하든 나머지가 즉시 함께 바뀌고, 비트 램프를 눌러 0과 1을 직접 켜고 끌 수 있습니다. AND, OR, 시프트 같은 비트 연산과 BCD 변환도 지원해서, PLC나 마이컴을 디버깅할 때 화면의 Hex 값이 실제로 어떤 비트 조합인지 바로 확인할 수 있습니다. 표기는 GX Works의 K(10진), H(16진) 방식을, 비트 램프는 Device Batch Monitor를 따랐습니다.

프로그래머 계산기

F~0 비트 램프 (탭하여 토글)
  • 이럴 때 씁니다: 모니터에 뜬 H0F00이 몇 번 비트인지 확인할 때, 통신 데이터의 바이트 순서를 뒤집어 볼 때, 표시기가 내보내는 BCD 값을 10진수로 되돌릴 때, 특정 비트만 남기는 마스크 값을 만들 때 씁니다.
  • 쓰는 순서: 위쪽에서 비트 폭을 고르고, H, K, O, B 중 입력할 진법 줄을 누른 뒤 값을 넣습니다. 나머지 진법과 비트 램프가 함께 바뀝니다.
  • 자세한 사용법: 계산기 제목 행의 도움말 버튼에서 기능 설명과 키보드 단축키 전체를 볼 수 있습니다.

프로그래머 계산기 도움말

이 도구로 할 수 있는 일

  • 값 하나를 16진수(H), 10진수(K), 8진수(O), 2진수(B)로 동시에 봅니다. 한 줄을 누르면 그 진법으로 입력할 수 있고, 나머지 줄은 자동으로 바뀝니다.
  • 비트 램프를 눌러 각 비트를 직접 켜고 끕니다. 어떤 비트가 서 있는지 눈으로 바로 확인할 수 있습니다.
  • 비트 폭(4bit, 8bit, WORD, DWORD, QWORD)을 골라 PLC 디바이스 크기에 맞춥니다.
  • AND, OR, XOR, NOT, 시프트, 회전 같은 비트 연산과 BCD 변환을 지원합니다.

알아두면 좋은 것

  • 부호 버튼을 켜면 10진수(K)를 음수까지 표시합니다. 끄면 0 이상만 표시합니다.
  • 비트 폭을 줄이면 넘치는 상위 비트가 잘립니다. 늘릴 때는 부호 설정에 따라 부호 확장 또는 0 확장을 적용합니다.
  • 오른쪽 시프트는 부호가 켜져 있으면 부호를 유지하는 산술 시프트로, 꺼져 있으면 논리 시프트로 동작합니다.
  • 스왑은 바이트 순서를 뒤집습니다. 통신 데이터의 엔디안을 맞출 때 씁니다.
