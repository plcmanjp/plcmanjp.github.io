엔지니어 도구

Modbus RTU 프레임 생성기

요청 ADU를 계산하고 spaced HEX, compact HEX, 필드 해설과 CRC byte 순서를 확인합니다.

계산과 복사 전용입니다. 시리얼 포트나 PLC에 연결하지 않으며 데이터를 송신하지 않습니다. 국번 0 방송과 40001 계열 참조 주소 직접 입력은 지원하지 않습니다.
